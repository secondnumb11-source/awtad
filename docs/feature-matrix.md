# مصفوفة ميزات أوتاد — مصدر البناء

هذه المصفوفة تجمع ما ظهر في ملف مواصفات أوتاد، والمواد المرفقة، وصفحات جسر الرسمية التي تمت مراجعتها.

## 1. الموارد البشرية الأساسية
- ملف موحد للموظف والبيانات الرقمية.
- هيكل تنظيمي: كيانات، فروع، إدارات، مواقع، مديرون، وظائف.
- إدارة متعددة الكيانات.
- دورة الموظف: مرشح → ما قبل المباشرة → مباشرة → تجربة → نشط → نقل/ترقية → إنهاء → تسوية.
- العقود والوثائق.
- الخدمة الذاتية للموظف والمدير.
- طلبات تحديث البيانات.
- نقل الموظف بين الإدارات.
- تغيير المدير.
- مجموعات الموظفين.
- الصلاحيات حسب الدور/القسم/المجموعة.
- تقارير الموظفين.

## 2. الحضور والدوام
- الورديات: بداية/نهاية، أيام العمل، الراحة، اليوم الاستثنائي، الإغلاق التلقائي للخروج عند الحاجة.
- جداول الورديات وتغييرها حسب التاريخ والتكرار.
- مواقع العمل.
- الحضور عبر القنوات المعتمدة، ومنها البصمة والموقع الجغرافي وفق المصدر.
- تصحيح وإضافة وحذف سجلات الحضور.
- تعديل/تغيير الوردية.
- الإجازات والأعذار والعمل الإضافي.
- أرصدة التعويض.
- الطلبات والموافقات.
- إدارة الأجهزة وطلبات تغيير الجهاز.
- تقارير الدوام.

## 3. التحكم اليدوي ومعالجة الطلبات
- تطبيق عمليات الموارد البشرية يدويًا عند الحاجة.
- إضافة/تعديل/حذف سجل دوام.
- تفويض مؤقت.
- إضافة/حذف يوم عطلة.
- تغيير وردية الموظف ليوم محدد.
- إضافة/حذف إجازة.
- طلب عمل إضافي.
- تعديل كل الحركات.
- تعبئة رصيد تعويضي.
- طلب عذر.
- معالجة طلبات الجهاز والدوام والوردية والتفويض والإجازة والتعويض والعذر والعمل الإضافي.

## 4. منصة المديرين
- إنشاء صلاحيات قابلة للتخصيص.
- إنشاء مستخدمين ومديرين.
- ربط المدير بقسم أو بموظفين.
- مجموعات للموظفين.
- منح الصلاحيات على مستوى المستخدم/المجموعة.
- بوابة مدير مصغرة بحسب الصلاحيات.

## 5. الإشعارات والتفاعل
- إشعارات لموظفين محددين أو موقع محدد أو مجموعة.
- أخبار الشركة.
- تقارير الإشعارات.
- تحقق من موقع الموظف.
- تهنئة أعياد الميلاد.
- استبيانات وقياس المشاركة/eNPS.
- مساعد ذكي للخدمة الذاتية.

## 6. الرواتب والمالية المرتبطة بالموظف
- مسيرات رواتب آلية.
- مجموعات رواتب.
- إضافي وبدلات وخصومات.
- مكافأة نهاية الخدمة والاستحقاقات.
- تكامل محاسبي/ERP.
- حماية الأجور وGOSI/SANED ضمن طبقة الامتثال.
- مصروفات الموظفين، OCR، سياسات، موافقات، تعويض وتسويات.
- العهد المالية.
- مزامنة المصروفات المعتمدة مع الرواتب.
- قيود محاسبية وربط ERP.
- رحلات العمل: طلب، موافقة، سياسة، حجز، دفع، متابعة، مقارنة المتوقع بالفعلي.

## 7. الامتثال السعودي
- سياسات الإجازات والدوام والراحة.
- GOSI، SANED، Muqeem، Mudad، WPS، والإشارة إلى Qiwa حسب المصادر.
- عقود وتأشيرات وإقامات.
- تنبيهات مخاطر المخالفات.
- قواعد رمضان والعطلات الرسمية.
- التحقق من الإجازات المرضية عبر التقارير الطبية الرسمية كما تنص مواصفات أوتاد، مع فصل التكامل عن منطق الأعمال.

## 8. التوظيف والمواهب
- ATS.
- طلب واعتماد الشاغر.
- صفحة وظائف ونماذج تقديم.
- قاعدة مرشحين.
- فرز ومطابقة السير الذاتية بالذكاء الاصطناعي.
- مراحل مقابلات وتقييمات قابلة للتخصيص.
- تكاملات جدولة المقابلات المذكورة في المواصفات.
- تشغيل عدة شواغر مع مطابقة الكفاءات.
- بدء ما قبل المباشرة بعد اختيار المرشح.

## 9. الأداء والتعلم والمشاركة
- دورات تقييم قابلة للتخصيص.
- تجربة ومراجعات سنوية.
- قوالب وتذكيرات وموافقات وتحليلات.
- التعلم العربي والإنجليزي، المسارات، المحتوى، الاختبارات، التقدم والتقارير.
- ربط التدريب بالأداء.
- إعلانات ورسائل واستبيانات ومشاركة الموظفين.

## 10. التحليلات
- لوحات وتقارير قابلة للتخصيص.
- القوى العاملة.
- الحضور والغياب والتأخر والإضافي.
- تكلفة الرواتب والمزايا.
- التوظيف والجدولة.
- الأداء والمشاركة والتعلم.
- المصروفات والالتزام بالميزانيات والسياسات.

## 11. التكاملات
- ERP والمحاسبة.
- البنوك.
- مزودو السفر.
- OCR.
- أنظمة الحكومة عبر adapters موثقة وقابلة للتحقق.
- لا تُنشأ endpoints حكومية وهمية.

## 12. طبقة أوتاد الإضافية
- إجراءات قابلة للتخصيص.
- تحديث سير العمل دون إعادة برمجة.
- صلاحيات دقيقة حسب المستخدم والكيان والقسم.
- رصد المخالفات.
- AI permission-aware.
- وكلاء AI ينفذون عبر أدوات النظام بعد authorization وقواعد الأعمال والتدقيق.
